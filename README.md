# Personal Mini-Toolkit

## What it does
This beginner-friendly Python program has a simple calculator, an interactive to-do list, and a number guessing game. The main menu repeats until you choose Quit. Invalid menu entries and common input mistakes are handled with helpful messages.

## How to run
1. Make sure Python 3 is installed.
2. Open a terminal in this project folder.
3. Run `python toolkit.py` (on some systems, use `py toolkit.py`).
